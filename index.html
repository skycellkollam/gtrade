General

Backend Connection (shared database for all devices)

Checking connection…
This app is centrally hosted, so the backend URL built into the file (updated by whoever maintains it) is what every device actually uses — this field will show that value automatically and can't be permanently overridden here. It only matters if you're running a local copy of the file with no built-in URL set.

Use "Push local data" once, from whichever device already has your real users/branches/evaluations, right after connecting a fresh backend for the first time. Doing it again later will overwrite the backend with this device's local copy — only use it if you're sure this device has the data you want to keep.

If this device is showing old/stale data that no longer matches the real sheet (e.g. a test entry that's since been removed), use "Clear This Device's Cached Data" — it wipes only this device's local copy and re-downloads everything fresh. It does not touch the shared backend, doesn't log you out, and is safe to use anytime. Your normal phone/browser "clear browsing data" option often doesn't fully clear this on its own, so use this button instead.

First-time backend setup

1. Create (or reuse) a Google Sheet. 2. Extensions → Apps Script, paste the code below (replacing anything there). 3. Deploy → New deployment (or Manage deployments → edit → New version) → Web app → Execute as "Me", Who has access "Anyone" → Deploy. 4. Copy the resulting URL into the field above, on every device.

Important performance fix: the sheet rebuild used to write one row at a time, which got slower as your record count grew and could time out on Approve/Pickup actions. It's now a single bulk write. If you already connected a backend before, redeploy with this updated code — it also no longer writes ID/device photo columns to the Evaluations sheet (removed on request) and looks up resale (Reached Office / Sold) details from their own small saved records instead of expecting them on each evaluation. Use Deploy → Manage deployments → Edit → New version, so the URL stays the same.

function doPost(e) {
  var out;
  try {
    var body = JSON.parse(e.postData.contents);
    var action = body.action;
    if (action === 'get') {
      out = { value: kvGet(body.key) };
    } else if (action === 'getBatch') {
      out = { values: kvGetBatch(body.keys || []) };
    } else if (action === 'set') {
      kvSet(body.key, body.value);
      if (body.key === 'evaluations-data') {
        try { rebuildEvaluationsSheet(JSON.parse(body.value)); } catch (err) {}
      }
      out = { ok: true };
    } else if (action === 'uploadImage') {
      out = uploadImageToDrive(body.dataUrl, body.filename);
    } else if (action === 'ping') {
      out = { ok: true, time: new Date().toISOString() };
    } else { out = { error: 'Unknown action: ' + action }; }
  } catch (err) { out = { error: String(err) }; }
  return ContentService.createTextOutput(JSON.stringify(out)).setMimeType(ContentService.MimeType.JSON);
}
